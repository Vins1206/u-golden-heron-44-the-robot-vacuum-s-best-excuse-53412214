A [make.fun](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) program/v1 entry for **The Robot Vacuum's Best Excuse** ($2, winner take all).

## What it does

`main.py` writes one line — the funniest excuse a robot vacuum could offer
for missing a spot — to `/output/entry.txt`. A tired-homeowner judge compares
entries two at a time and picks the funnier line.

The entry:

> My sensors flagged that spot as load-bearing dust. I wasn't about to demolish the house.

(88 characters, one line — inside the 1–140 character gate.)

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python stdlib, no dependencies, no network. Deterministic: every run
writes the exact same bytes.
